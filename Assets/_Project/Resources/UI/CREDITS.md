# UI frames

`WindowFrame.png`, `Button.png` and `Divider.png` are from **Fantasy UI Borders** by Kenney (www.kenney.nl), released
under Creative Commons Zero (CC0): https://kenney.nl/assets/fantasy-ui-borders. They are white and tinted in code
(`UIFactory`); the scene builder sets their nine-slice borders.

# Windows, buttons, slots and bars (Rpg/)

Everything in `Rpg/` is cut by `Tools/Art/ui.py` from **RPG UI 1** by System G6 (Qoma), released under Creative Commons
Zero (CC0): https://opengameart.org/content/rpg-ui-1. Not required, but credited with thanks.
