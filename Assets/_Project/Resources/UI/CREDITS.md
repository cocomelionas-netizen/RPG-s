# UI frames

`WindowFrame.png`, `Button.png` and `Divider.png` are from **Fantasy UI Borders** by Kenney (www.kenney.nl), released
under Creative Commons Zero (CC0): https://kenney.nl/assets/fantasy-ui-borders. They are white and tinted in code
(`UIFactory`); the scene builder sets their nine-slice borders.

# Windows, buttons, slots and bars (Rpg/)

Everything in `Rpg/` is cut by `Tools/Art/ui.py` from **RPG UI 1** by System G6 (Qoma), released under Creative Commons
Zero (CC0): https://opengameart.org/content/rpg-ui-1. Not required, but credited with thanks.

# World map badges (Map/)

The glyphs on the badges in `Map/` are from **game-icons.net**, released under Creative Commons Attribution 3.0
(CC-BY 3.0): https://game-icons.net, https://github.com/game-icons/icons. By Lorc (castle, crowned-skull,
crystal-cluster, crossed-swords, visored-helm, potion-ball, gem-pendant, beer-stein, cauldron, open-book, ankh,
swap-bag, conversation, compass) and Delapouite (cave-entrance, two-coins). Drawn onto the badges by `Tools/Art/worldmap.py`; the
island picture `Map/World.png` is this project's own.
