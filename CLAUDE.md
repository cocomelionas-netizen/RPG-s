# RPG-s — notes for Claude

Unity 6 (6000.6.4f1) 2D isometric MMORPG, URP 2D, Netcode for GameObjects 2.13, Input System, UI built in code
(`UIFactory`), server authority. A personal test project that takes as much as it can from **Dreadmyst**.
Players test the WebGL build at https://cocomelionas-netizen.github.io/RPG-s/ (Offline mode).

## Working rules (from the owner)

- Answer the owner in **Lithuanian**; code, names and comments in English, matching the existing style.
- After each change: commit and push straight to `main`. Never force-push. Never touch GitHub Secrets.
- Check the CI build: `https://api.github.com/repos/cocomelionas-netizen/RPG-s/actions/runs?per_page=1`
  (and `/runs/{id}/jobs` on failure); builds take 10–15 min, a newer push cancels an older run.
  Tell the owner the result and what to test in the game.
- No Unity in the cloud: the scene and prefabs are generated by `Assets/_Project/Scripts/Editor/TestSceneBuilder.cs`
  in CI. Never hand-edit `.unity`/`.prefab`. New C# files need no `.meta`; never delete or change existing `.meta`.
- New tests go in `Assets/_Project/Tests/PlayMode`.
- Before pushing, run `bash Tools/CompileCheck/check.sh` (setup once: `bash Tools/CompileCheck/setup.sh`).
  Editor scripts are not compiled there — re-read builder changes carefully (CI fails on any editor error).
- Do not try to get data from Dreadmyst's live server (not allowed). Client data is fine.

## Dreadmyst data

Client files come from `https://github.com/DreadmystRPG/steam` (blobless clone is enough): `game.db` (SQLite:
`item_template`, `spell_template`, `npc_template`, `affix_template`, `gameobject_template`, `material_chance_*`,
`player_class_stats`, `npc_vendor`, `quest_template`...), `bin/Dreadmyst.exe` (strings, stat ids/costs), `maps/`.
What was taken and how it maps is documented in `Docs/DreadmystLayout.md` (Lithuanian). Generated data lives in
`Scripts/Editor/Dreadmyst*.cs` (start area, gear, affixes, spells).

## What exists (short)

World: Dreadmyst's start region (Pilgrim's Refuge → St. Revere), its monsters/chests/waystones, M world map.
Stats: all Dreadmyst stats bought with experience (C, three pages). Items: Dreadmyst gear by level and material,
crafted at class vendors from materials monsters drop; 7145 affixes; potions/serums; gems; loot window with sparkles.
Chests: crates (gold), locked chests (Lockpicking 2 × level). Spells: Dreadmyst Paladin/Ranger/Mage spells to level 20,
Tomes at trainers (Halfrid, Kelda, Gyldan), ranks for experience, spellbook (P), bar keys 1-4 and 7-0, potions 5-6,
status effects (`StatusEffects`).
